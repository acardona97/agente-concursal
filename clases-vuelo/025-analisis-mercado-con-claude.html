Morning Brief Automático con Claude

Construir un resumen diario de mercados que Claude genera cada mañana. BTC, ETH, SPY, DXY + análisis macro en 200 palabras.

1. El concepto: qué es un Morning Brief

Los traders profesionales empiezan el día con un brief: precio de activos clave, noticias relevantes, contexto macro. El nuestro se genera automáticamente cada mañana y te da el contexto que necesitas para tomar decisiones de inversión en 2 minutos.

Es como el resumen ejecutivo que le piden a los analistas de un fondo de inversión cada mañana antes de la apertura del mercado. Solo que en vez de un analista humano (que cobra $8,000/mes), lo genera Claude en 30 segundos y $0.03 de API.
QUARTA MORNING BRIEF · 2024-01-15 07:00
── PRECIOS ──────────────────────────────
BTC: $67,420 (+2.3% 24h) (+8.1% 7d)
ETH: $3,580 (+1.1% 24h) (+5.2% 7d)
SPY: $478.20 (-0.4% 24h) (+1.8% 7d)
DXY: 104.2 (+0.2% 24h) (dólar fuerte)
── ANÁLISIS CLAUDE ──────────────────────
Bitcoin mantiene momentum alcista con volumen sostenido, cotizando por encima de su MA30. La correlación inversa con DXY (dólar fuerte = presión sobre cripto) puede frenar el avance. SPY en corrección leve no indica risk-off generalizado todavía. El Fear & Greed en 71 (codicia) sugiere precaución en nuevas posiciones. Contexto clave: decisión de tasas Fed el miércoles.
── SEÑAL DEL DÍA ────────────────────────
WATCH — Momentum positivo pero precaución con DXY

3. Análisis de Correlaciones: BTC, SPY, DXY

Por qué mirar más allá de BTC solo

  • BTC vs SPY: en 2020-2023, alta correlación. Cuando el mercado de acciones cae, BTC a menudo también cae (risk-off). Esta correlación no es constante.
  • BTC vs DXY (dólar): correlación inversa clásica. Dólar fuerte → presión sobre activos riesgosos. Dólar débil → capital fluye hacia cripto y acciones.
  • ETH vs BTC: ETH tiende a seguir a BTC pero con más volatilidad (beta más alto).

Para el brief: Claude analiza estas correlaciones en tiempo real y las incluye en el contexto macro.

4. Código Completo — Morning Brief Automático

#!/usr/bin/env python3
"""
Morning Brief Automático — Quarta
=====================================
Genera un resumen diario de mercados con análisis de Claude.
Lee BTC, ETH, SPY, DXY y genera análisis macro de 200 palabras.

Instalación:
  pip install anthropic yfinance requests python-dotenv

Uso:
  python morning_brief.py                # ejecutar ahora
  python morning_brief.py --save         # guardar en archivo
  # Automatizar: agregar a crontab → 0 7 * * 1-5 python morning_brief.py
"""

import os
import sys
import json
import requests
from datetime import datetime, timedelta
from dotenv import load_dotenv
import anthropic

# yfinance puede tener problemas de instalación en algunos entornos
# Si falla: pip install yfinance --upgrade
try:
    import yfinance as yf
    YFINANCE_DISPONIBLE = True
except ImportError:
    YFINANCE_DISPONIBLE = False
    print("[BRIEF][WARN] yfinance no instalado. Usando solo CoinGecko para cripto.")

load_dotenv()
cliente = anthropic.Anthropic()
MODELO = "claude-sonnet-4-5"  # Sonnet es suficiente para análisis de texto


# ─── 1. OBTENER DATOS DE MERCADO ────────────────────────────────

def obtener_datos_cripto() -> dict:
    """
    Obtiene BTC y ETH desde CoinGecko.
    Retorna precios actuales y cambios.
    """
    url = "https://api.coingecko.com/api/v3/simple/price"
    params = {
        "ids": "bitcoin,ethereum",
        "vs_currencies": "usd",
        "include_24hr_change": "true",
        "include_7d_change": "true"
    }
    try:
        r = requests.get(url, params=params, timeout=10)
        r.raise_for_status()
        datos = r.json()
        return {
            "BTC": {
                "precio": datos["bitcoin"]["usd"],
                "cambio_24h": round(datos["bitcoin"]["usd_24h_change"], 2),
                "cambio_7d": round(datos["bitcoin"].get("usd_7d_change", 0), 2)
            },
            "ETH": {
                "precio": datos["ethereum"]["usd"],
                "cambio_24h": round(datos["ethereum"]["usd_24h_change"], 2),
                "cambio_7d": round(datos["ethereum"].get("usd_7d_change", 0), 2)
            }
        }
    except Exception as e:
        print(f"[BRIEF][ERROR] CoinGecko: {e}")
        return {}


def obtener_datos_tradicionales() -> dict:
    """
    Obtiene SPY (S&P500) y DXY (índice dólar) con yfinance.
    Estos activos son la referencia macro para interpretar cripto.
    """
    if not YFINANCE_DISPONIBLE:
        return {"SPY": None, "DXY": None}

    resultado = {}

    for ticker_id, nombre in [("SPY", "SPY"), ("DX-Y.NYB", "DXY")]:
        try:
            ticker = yf.Ticker(ticker_id)
            # Obtener datos de los últimos 7 días
            hist = ticker.history(period="7d")

            if hist.empty:
                resultado[nombre] = None
                continue

            precio_actual = hist["Close"].iloc[-1]
            precio_ayer = hist["Close"].iloc[-2] if len(hist) > 1 else precio_actual
            precio_7d = hist["Close"].iloc[0]

            cambio_24h = ((precio_actual - precio_ayer) / precio_ayer) * 100
            cambio_7d = ((precio_actual - precio_7d) / precio_7d) * 100

            resultado[nombre] = {
                "precio": round(precio_actual, 2),
                "cambio_24h": round(cambio_24h, 2),
                "cambio_7d": round(cambio_7d, 2)
            }
        except Exception as e:
            print(f"[BRIEF][WARN] {nombre}: {e}")
            resultado[nombre] = None

    return resultado


def obtener_fear_greed() -> dict:
    """Índice Fear & Greed del mercado cripto."""
    try:
        r = requests.get("https://api.alternative.me/fng/", timeout=8)
        d = r.json()["data"][0]
        return {"valor": int(d["value"]), "texto": d["value_classification"]}
    except:
        return {"valor": 50, "texto": "Neutral"}


def simular_noticias() -> list:
    """
    Retorna noticias simuladas para el brief.
    En producción: conectar a NewsAPI, CryptoPanic, o RSS feeds.
    newsapi.org tiene plan gratuito (100 req/día).
    """
    # Simulación para fines educativos
    # En producción usa: pip install newsapi-python
    return [
        "Fed mantiene tasas estables, mercados reaccionan positivamente",
        "Volumen de Bitcoin en exchanges en mínimo de 6 meses",
        "ETF de Bitcoin spot supera $50B en activos bajo gestión",
        "Inflación USA cae a 3.1%, cerca del objetivo del 2% de la Fed"
    ]


# ─── 2. ANÁLISIS CON CLAUDE ──────────────────────────────────────

def generar_analisis_macro(datos_mercado: dict, fear_greed: dict, noticias: list) -> str:
    """
    Claude genera un análisis macro de ~200 palabras que contextualiza
    todos los datos del mercado. No es un bot de trading — es un analista
    que sintetiza información para el inversor.
    """

    # Formatear los datos para el prompt
    datos_formateados = json.dumps(datos_mercado, indent=2, ensure_ascii=False)
    noticias_texto = "\n".join(f"- {n}" for n in noticias)

    prompt = f"""Eres el analista de mercados de Quarta, firma legal colombiana con inversiones
propias en cripto y mercados tradicionales. Genera el morning brief del día.

DATOS DE MERCADO HOY:
{datos_formateados}

FEAR & GREED INDEX: {fear_greed['valor']}/100 ({fear_greed['texto']})

NOTICIAS RELEVANTES:
{noticias_texto}

Escribe un análisis de exactamente 200 palabras que incluya:
1. Estado actual de los mercados (2-3 oraciones)
2. Correlaciones relevantes: cómo se relacionan BTC, SPY y DXY hoy
3. El dato o noticia más importante para tener en cuenta
4. Una perspectiva de corto plazo (1-3 días)
5. Nivel de riesgo general: BAJO / MEDIO / ALTO

Termina con: "SEÑAL DEL DÍA: [HOLD/WATCH/ALERT] — [justificación en 10 palabras]"

Tono: analítico, directo, sin hipérbole. Incluye siempre el disclaimer:
"Este análisis es solo informativo, no es consejo de inversión."

Escribe en español."""

    try:
        respuesta = cliente.messages.create(
            model=MODELO,
            max_tokens=600,
            messages=[{"role": "user", "content": prompt}]
        )
        return respuesta.content[0].text.strip()
    except Exception as e:
        return f"[ERROR en análisis Claude: {e}]"


# ─── 3. FORMATEAR EL BRIEF ──────────────────────────────────────

def formatear_brief(datos_mercado: dict, fear_greed: dict, analisis: str) -> str:
    """
    Genera el morning brief completo en formato Markdown legible en terminal.
    """
    ts = datetime.now().strftime("%Y-%m-%d %H:%M")

    def cambio_str(v):
        if v is None: return "N/A"
        signo = "+" if v > 0 else ""
        return f"{signo}{v:.2f}%"

    def precio_str(activo, datos):
        if datos is None:
            return f"{activo}: N/A"
        p = datos['precio']
        c24 = cambio_str(datos.get('cambio_24h'))
        c7d = cambio_str(datos.get('cambio_7d'))
        simbolo = "$" if activo != "DXY" else ""
        return f"{activo}: {simbolo}{p:,.2f}  ({c24} 24h)  ({c7d} 7d)"

    lineas = [
        f"",
        f"{'═'*58}",
        f"  QUARTA MORNING BRIEF · {ts}",
        f"{'═'*58}",
        f"",
        f"── PRECIOS ──────────────────────────────────────────",
    ]

    for activo in ["BTC", "ETH", "SPY", "DXY"]:
        datos = datos_mercado.get(activo)
        lineas.append(f"  {precio_str(activo, datos)}")

    lineas += [
        f"",
        f"  Fear & Greed: {fear_greed['valor']}/100 ({fear_greed['texto']})",
        f"",
        f"── ANÁLISIS CLAUDE ──────────────────────────────────",
        f"",
    ]

    # Indentar el análisis
    for linea in analisis.split('\n'):
        lineas.append(f"  {linea}")

    lineas += [
        f"",
        f"{'═'*58}",
        f""
    ]

    return "\n".join(lineas)


# ─── 4. FUNCIÓN PRINCIPAL ───────────────────────────────────────

def ejecutar_brief(guardar: bool = False):
    """
    Orquesta todo el flujo del morning brief.
    Si guardar=True, guarda el resultado en briefs/YYYY-MM-DD.txt
    """
    print("[BRIEF][INFO] Obteniendo datos de mercado...")

    # Obtener todos los datos en paralelo (aquí secuencial por simplicidad)
    datos_cripto = obtener_datos_cripto()
    datos_trad = obtener_datos_tradicionales()
    fear_greed = obtener_fear_greed()
    noticias = simular_noticias()

    # Consolidar datos
    datos_mercado = {**datos_cripto, **datos_trad}

    print("[BRIEF][INFO] Generando análisis con Claude...")
    analisis = generar_analisis_macro(datos_mercado, fear_greed, noticias)

    # Formatear y mostrar
    brief = formatear_brief(datos_mercado, fear_greed, analisis)
    print(brief)

    # Guardar opcionalmente
    if guardar:
        fecha = datetime.now().strftime("%Y-%m-%d")
        os.makedirs("briefs", exist_ok=True)
        archivo = f"briefs/{fecha}.txt"
        with open(archivo, "w", encoding="utf-8") as f:
            f.write(brief)
        print(f"[BRIEF][INFO] Guardado en {archivo}")

    return brief


if __name__ == "__main__":
    guardar = "--save" in sys.argv
    ejecutar_brief(guardar=guardar)

6. QUARTA — Alimentar decisiones de inversión de la firma

Cómo este sistema es útil para Quarta

Una firma legal que también invierte su propio capital (o asesora clientes en inversiones) necesita contexto de mercado sin dedicar horas a leer Bloomberg. Este brief da:

  • Contexto macro en 2 minutos: antes de tomar cualquier decisión de inversión del día
  • Correlaciones BTC/DXY: relevante si Quarta mantiene BTC en su tesorería
  • Señal diaria: no una recomendación, sino un calibrador de atención
  • Historial en briefs/: puedes revisar qué decía el análisis la semana antes de un movimiento importante
