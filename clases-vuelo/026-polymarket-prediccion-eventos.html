Polymarket — Mercados de Predicción con IA

El lugar donde el conocimiento legal de Andrés se convierte en ventaja competitiva financiera.

1. Qué es Polymarket y cómo funciona

Polymarket es un mercado de predicción descentralizado. En vez de apostar por si sube o baja un activo, apuestas por si un evento ocurre o no. Las respuestas son binarias: SÍ o NO.

Imagina que la Superintendencia de Sociedades va a decidir si aprueba o rechaza un acuerdo de reorganización de una empresa importante. En Polymarket, podrías comprar "SÍ" a que lo aprueba. Si lo aprueba: te pagan $1 por acción. Si lo rechaza: pierdes lo que invertiste. El precio actual de ese "SÍ" (ej: $0.65) refleja lo que el mercado cree que es la probabilidad de que ocurra (65%). Si tú crees que la probabilidad real es 80% (porque eres abogado y entiendes el caso), comprando a $0.65 tienes una ventaja esperada positiva.

La mecánica en 3 puntos

  1. Eventos con fecha de resolución: "¿Subirá BTC a $100K antes del 31 de dic?" o "¿Ganará X la elección?"
  2. Precios = probabilidades implícitas: precio $0.30 = el mercado dice 30% de probabilidad
  3. Ventaja = cuando tu estimación > precio del mercado: si crees que es 60% y cotiza a 30%, hay ventaja esperada

4. Código Completo — Agente de Análisis Polymarket

#!/usr/bin/env python3
"""
Agente de Análisis Polymarket para Quarta
==========================================
Conecta a la API pública de Polymarket, filtra mercados relevantes
(legales, regulatorios, Colombia), y usa Claude para estimar
la probabilidad real vs la del mercado.

Instalación:
  pip install anthropic requests python-dotenv
"""

import os
import json
import requests
from datetime import datetime
from dotenv import load_dotenv
import anthropic

load_dotenv()
cliente = anthropic.Anthropic()
MODELO = "claude-opus-4-5"

# Keywords que interesan a Andrés (ajustar según intereses)
KEYWORDS_RELEVANTES = [
    "colombia", "bitcoin", "crypto", "regulation",
    "fed", "interest rate", "election", "legal",
    "sec", "court", "supreme court"
]

# Categorías de alta ventaja para Andrés
KEYWORDS_VENTAJA = [
    "colombia", "legal", "court", "regulation",
    "crypto regulation", "sec"
]


# ─── 1. OBTENER MERCADOS ────────────────────────────────────────

def obtener_mercados(limit: int = 50) -> list:
    """
    Obtiene los mercados activos de Polymarket.
    Retorna lista de mercados con sus precios y metadatos.
    """
    url = "https://gamma-api.polymarket.com/markets"
    params = {
        "active": "true",
        "limit": limit,
        "order": "volume",
        "ascending": "false"  # los de mayor volumen primero
    }
    try:
        r = requests.get(url, params=params, timeout=15)
        r.raise_for_status()
        return r.json()
    except requests.RequestException as e:
        print(f"[POLY][ERROR] No se pudo conectar a Polymarket: {e}")
        return _mercados_simulados()  # fallback con datos de ejemplo


def _mercados_simulados() -> list:

def filtrar_mercados_relevantes(mercados: list) -> list:
    """
    Filtra mercados que son relevantes para el perfil de Andrés.
    Prioriiza temas legales, regulatorios y cripto.
    """
    relevantes = []
    for m in mercados:
        pregunta = m.get("question", "").lower()
        if any(kw in pregunta for kw in KEYWORDS_RELEVANTES):
            m["tiene_ventaja"] = any(kw in pregunta for kw in KEYWORDS_VENTAJA)
            relevantes.append(m)
    return relevantes


# ─── 2. ANALIZAR CON CLAUDE ──────────────────────────────────────

def analizar_mercado(mercado: dict) -> dict:
    """
    Claude analiza un mercado de Polymarket y genera:
    - Probabilidad estimada propia (0-100%)
    - Comparación con el precio del mercado
    - Razonamiento
    - Nivel de ventaja de Andrés en este mercado
    """
    precio_si = float(mercado["outcomePrices"][0])
    prob_mercado = round(precio_si * 100, 1)

    tiene_ventaja = mercado.get("tiene_ventaja", False)
    contexto_ventaja = ""
    if tiene_ventaja:
        contexto_ventaja = """
NOTA: Este mercado está relacionado con derecho colombiano, regulación cripto,
o temas judiciales. El analista tiene experiencia como abogado colombiano
especializado en derecho concursal y propiedad intelectual, con conocimiento
de la Superintendencia de Sociedades, la SIC, la DIAN, y los tribunales colombianos.
Su estimación en estos temas puede diferir significativamente del mercado general."""

    prompt = f"""Eres un analista de mercados de predicción con expertise en derecho,
regulación y mercados financieros.

Analiza el siguiente mercado de Polymarket:

PREGUNTA: {mercado['question']}
PROBABILIDAD ACTUAL DEL MERCADO: {prob_mercado}% (precio SÍ: ${precio_si:.2f})
VOLUMEN TOTAL: ${float(mercado.get('volume', 0)):,.0f}
FECHA DE RESOLUCIÓN: {mercado.get('endDate', 'N/A')}
{contexto_ventaja}

Responde en JSON con este formato exacto:
{{
  "prob_estimada": ,
  "razonamiento": "<2-3 oraciones explicando tu estimación>",
  "factores_clave": ["factor 1", "factor 2"],
  "discrepancia": ,
  "nivel_oportunidad": "ALTA|MEDIA|BAJA|NINGUNA",
  "ventaja_dominio": "",
  "confianza": "ALTA|MEDIA|BAJA",
  "nota": "Esto es análisis especulativo, no consejo financiero"
}}"""

    try:
        respuesta = cliente.messages.create(
            model=MODELO,
            max_tokens=600,
            messages=[{"role": "user", "content": prompt}]
        )
        texto = respuesta.content[0].text.strip()
        inicio = texto.find('{')
        fin = texto.rfind('}') + 1
        if inicio >= 0 and fin > inicio:
            return json.loads(texto[inicio:fin])
    except Exception as e:
        print(f"[POLY][ERROR] Análisis Claude: {e}")

    return {
        "prob_estimada": prob_mercado,
        "razonamiento": "Error en análisis",
        "discrepancia": 0,
        "nivel_oportunidad": "BAJA",
        "confianza": "BAJA"
    }


# ─── 3. MOSTRAR RESULTADOS ──────────────────────────────────────

def mostrar_analisis(mercado: dict, analisis: dict):
    """Muestra el análisis de un mercado en formato legible."""
    reset = "\033[0m"
    gold = "\033[33m"
    green = "\033[92m"
    yellow = "\033[93m"
    red = "\033[91m"
    dim = "\033[90m"

    precio_si = float(mercado["outcomePrices"][0])
    prob_mercado = precio_si * 100
    prob_estimada = analisis.get("prob_estimada", prob_mercado)
    discrepancia = analisis.get("discrepancia", 0)

    # Color de la discrepancia
    if abs(discrepancia) > 15:
        color_disc = green if discrepancia > 0 else red
        oportunidad = "★★★"
    elif abs(discrepancia) > 8:
        color_disc = yellow
        oportunidad = "★★"
    else:
        color_disc = dim
        oportunidad = "★"

    print(f"\n{gold}{'─'*56}{reset}")
    print(f"{gold}  {mercado['question'][:55]}{reset}")
    print(f"  Mercado: {prob_mercado:.0f}%  →  Claude: {prob_estimada:.0f}%  {color_disc}(Δ {discrepancia:+.0f}pp){reset}  {oportunidad}")
    print(f"  Volumen: ${float(mercado.get('volume',0)):,.0f}   Nivel: {analisis.get('nivel_oportunidad','N/A')}")
    print(f"\n  {analisis.get('razonamiento','')[:200]}")

    if analisis.get("ventaja_dominio"):
        print(f"\n  {green}VENTAJA:{reset} {analisis['ventaja_dominio'][:150]}")


# ─── 4. FUNCIÓN PRINCIPAL ───────────────────────────────────────

def ejecutar_agente_polymarket(solo_ventaja: bool = False):
    """
    Orquesta el análisis completo de mercados Polymarket.
    Si solo_ventaja=True, analiza solo los mercados donde Andrés tiene ventaja.
    """
    print("[POLY][INFO] Conectando a Polymarket...")
    mercados = obtener_mercados(limit=50)

    print(f"[POLY][INFO] {len(mercados)} mercados totales. Filtrando relevantes...")
    relevantes = filtrar_mercados_relevantes(mercados)

    if solo_ventaja:
        relevantes = [m for m in relevantes if m.get("tiene_ventaja", False)]

    print(f"[POLY][INFO] {len(relevantes)} mercados relevantes para analizar.")
    print(f"[POLY][INFO] Analizando con Claude (puede tomar 1-2 min)...\n")

    resultados = []
    for i, mercado in enumerate(relevantes[:10], 1):  # máximo 10 para controlar costos
        print(f"[POLY][INFO] Analizando {i}/{min(10, len(relevantes))}...")
        analisis = analizar_mercado(mercado)
        mostrar_analisis(mercado, analisis)
        resultados.append({"mercado": mercado, "analisis": analisis})

    # Resumen final: mercados con mayor oportunidad
    print(f"\n\033[33m{'═'*56}\033[0m")
    print(f"\033[33m  TOP OPORTUNIDADES (discrepancia > 10pp)\033[0m")
    print(f"\033[33m{'═'*56}\033[0m")

    top = sorted(resultados,
                 key=lambda x: abs(x["analisis"].get("discrepancia", 0)),
                 reverse=True)[:3]

    for r in top:
        disc = r["analisis"].get("discrepancia", 0)
        pregunta = r["mercado"]["question"][:60]
        print(f"  {'↑' if disc > 0 else '↓'} {pregunta}")
        print(f"    Discrepancia: {disc:+.0f}pp   Confianza: {r['analisis'].get('confianza','N/A')}")

    print(f"\n\033[90m  Disclaimer: Polymarket no está disponible para usuarios en Colombia.\033[0m")
    print(f"\033[90m  Este análisis es solo educativo. Verifica regulaciones locales.\033[0m\n")

    return resultados


if __name__ == "__main__":
    ejecutar_agente_polymarket(solo_ventaja=False)

5. QUARTA — La ventaja competitiva de Andrés en Polymarket

Por qué el conocimiento legal colombiano da ventaja

La mayoría de participantes en Polymarket son traders estadounidenses y europeos. Sus modelos son buenos para política americana, cripto, y macro global. Pero para eventos regulatorios colombianos:

El mercado piensa

  • Basado en noticias internacionales
  • Sin contexto institucional colombiano
  • Sin leer fallos anteriores de la SIC
  • Sin entender la dinámica política de la Supersociedades

Andrés sabe

  • Cómo razona la Supersociedades en casos similares
  • Precedentes de la SIC en PI
  • Velocidad real de procesos de la DIAN
  • Si un acuerdo de reorganización tiene viabilidad real

Nichos específicos de alta ventaja

  • Decisiones de la Superintendencia de Sociedades en casos de reorganización de empresas conocidas Andrés conoce el proceso por dentro: plazos reales, criterios de aprobación, tendencias recientes
  • Fallos de la SIC sobre propiedad intelectual y marcas en Colombia Área de expertise de Quarta — puede estimar probabilidades con alta confianza
  • Regulación de criptomonedas en Colombia (DIAN, URF, Superfinanciera) Conoce el ritmo legislativo colombiano mejor que un trader de New York
  • Decisiones de la Corte Constitucional o el Consejo de Estado sobre temas económicos Entiende los argumentos legales en juego y el historial de estas cortes

Aviso legal importante

Polymarket opera en blockchain (Polygon) y usa USDC. En Colombia, la regulación de mercados de predicción y apuestas es compleja. Antes de participar con dinero real, verificar:

  • Restricciones de acceso para usuarios colombianos (Polymarket tiene geo-restricciones)
  • Tratamiento tributario de ganancias en DIAN
  • Si tus conocimientos como abogado constituyen "información privilegiada" en algún caso específico

Para fines de este curso: el agente de análisis tiene valor total como herramienta de entrenamiento y análisis académico, independientemente de si participas en Polymarket.
