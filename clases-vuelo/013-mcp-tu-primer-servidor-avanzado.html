Micro-clase · TypedDict en Python (5 min)

¿Qué es TypedDict y por qué lo necesitas?

TypedDict es una forma de decirle a Python (y a tu editor) exactamente qué campos tiene un diccionario y qué tipo tiene cada campo. No es obligatorio en tiempo de ejecución, pero previene errores y hace el código legible.

# Sin TypedDict — funciona pero es opaco
credito = {"acreedor": "ACREEDOR_1", "valor": 50000000, "clase": "primera"}

# Con TypedDict — Python sabe qué campos existen y de qué tipo
from typing import TypedDict

class Credito(TypedDict):
    acreedor: str        # nombre del acreedor
    valor:    int        # valor en pesos colombianos
    clase:    str        # "primera", "segunda", etc.
    radicado: str        # número de radicación

# Ahora tu editor te avisa si te equivocas de campo
credito: Credito = {
    "acreedor": "[ACREEDOR]",
    "valor": 50_000_000,
    "clase": "primera",
    "radicado": "2024-01234-00"
}

En MCP lo usas para definir los parámetros de entrada y salida de cada tool. El SDK genera automáticamente el JSON Schema que Claude necesita para saber cómo llamar la tool.

1. El SDK oficial de MCP para Python

Anthropic publicó un SDK oficial llamado mcp. Es diferente del SDK de Anthropic que ya usas (ese es para llamar a Claude). Este es para construir servidores que Claude puede llamar.

# Para tu agente concursal — agregar a requirements.txt
mcp>=1.0.0

# Instalar localmente
pip install mcp
Importante: El SDK mcp abstrae todo el JSON-RPC. No tienes que escribir los {"jsonrpc": "2.0"...} manualmente. Defines tus tools como funciones Python y el SDK hace el resto.

2. MCP Server completo — Relatoría CSJ (simulado)

Este es el código completo de un servidor MCP para consultar jurisprudencia. Cada línea tiene comentario en español. Léelo de arriba a abajo como si fuera un escrito procesal.

archivo: mcp_csj_server.py
"""
mcp_csj_server.py
Servidor MCP para consultar la Relatoría de la CSJ.
Expone dos tools: buscar_jurisprudencia y obtener_sentencia.

Para correr: python mcp_csj_server.py
(Usa transport stdio para Claude Code CLI,
 o HTTP/SSE para conectar desde Claude.ai)
"""

# ── Imports ──────────────────────────────────────────────────────────
import asyncio
import json
import os
from typing import Any, TypedDict
from datetime import date

# SDK oficial de MCP — la pieza central
from mcp.server import Server
from mcp.server.stdio import stdio_server
from mcp import types


# ── TypedDicts — contratos de datos ──────────────────────────────────

class BusquedaParams(TypedDict):
    """Parámetros para buscar jurisprudencia."""
    termino:  str   # palabra clave a buscar
    sala:     str   # "Civil", "Penal", "Laboral", "Comercio"
    año:      int   # año de la sentencia (ej: 2023)

class SentenciaParams(TypedDict):
    """Parámetros para obtener una sentencia específica."""
    radicado: str   # número de radicado completo


# ── Instanciar el servidor ───────────────────────────────────────────
# "quarta-csj-server" es el nombre que verá Claude
servidor = Server("quarta-csj-server")


# ── Tool 1: buscar_jurisprudencia ────────────────────────────────────
# @servidor.list_tools() registra la tool — Claude verá su definición
@servidor.list_tools()
async def listar_tools() -> list[types.Tool]:
    """
    Claude llama esto para saber qué tools existen.
    Retorna la lista completa con sus esquemas JSON.
    """
    return [
        types.Tool(
            name="buscar_jurisprudencia",
            # La descripción es CRÍTICA — Claude la usa para decidir cuándo llamar esta tool
            description="""Busca sentencias de la Corte Suprema de Justicia colombiana
en la Relatoría. Útil para encontrar precedentes sobre reorganización,
liquidación judicial, calificación de créditos y acuerdos de reorganización
bajo la Ley 1116 de 2006.""",
            inputSchema={
                "type": "object",
                "properties": {
                    "termino": {
                        "type": "string",
                        "description": "Palabra clave o frase de búsqueda"
                    },
                    "sala": {
                        "type": "string",
                        "enum": ["Civil", "Casacion Civil", "Laboral"],
                        "description": "Sala de la CSJ (default: Casacion Civil)"
                    },
                    "año": {
                        "type": "integer",
                        "description": "Año de la sentencia (ej: 2023)"
                    }
                },
                "required": ["termino"]  # solo termino es obligatorio
            }
        ),
        types.Tool(
            name="obtener_sentencia",
            description="""Obtiene el texto completo de una sentencia de la CSJ
dado su número de radicado. Usar después de buscar_jurisprudencia
para obtener el texto completo de un fallo relevante.""",
            inputSchema={
                "type": "object",
                "properties": {
                    "radicado": {
                        "type": "string",
                        "description": "Número de radicado completo (ej: SC1234-2023)"
                    }
                },
                "required": ["radicado"]
            }
        )
    ]


# ── Manejador de llamadas a tools ────────────────────────────────────
# @servidor.call_tool() se ejecuta CADA VEZ que Claude llama una tool
@servidor.call_tool()
async def ejecutar_tool(name: str, arguments: dict[str, Any]) -> list[types.TextContent]:
    """
    Punto de entrada para todas las llamadas a tools.
    'name' es el nombre de la tool que llamó Claude.
    'arguments' son los parámetros que Claude eligió enviar.
    """

    # ── Despachar según nombre de la tool ───────────────────────────
    if name == "buscar_jurisprudencia":
        return await _buscar_jurisprudencia(arguments)

    elif name == "obtener_sentencia":
        return await _obtener_sentencia(arguments)

    else:
        # Tool desconocida — error estándar MCP
        raise ValueError(f"Tool '{name}' no existe en este servidor")


# ── Implementación de buscar_jurisprudencia ──────────────────────────
async def _buscar_jurisprudencia(args: dict) -> list[types.TextContent]:
    """Busca sentencias en la Relatoría de la CSJ."""

    # Validar parámetros — nunca confíes en que Claude envió lo correcto
    termino = args.get("termino", "").strip()
    if not termino:
        # Retornar error como texto — MCP no usa excepciones para errores de negocio
        return [types.TextContent(
            type="text",
            text="Error: se requiere un término de búsqueda."
        )]

    sala = args.get("sala", "Casacion Civil")
    año  = args.get("año", date.today().year)

    try:
        # AQUÍ iría la llamada real a la API de la Relatoría CSJ
        # Por ahora: datos simulados con estructura real
        resultados = await _consultar_relatoria_csj(termino, sala, año)

        # Formatear respuesta — el texto que Claude leerá
        texto = f"Resultados para '{termino}' en Sala {sala} ({año}):\n\n"
        for i, r in enumerate(resultados, 1):
            texto += f"{i}. {r['radicado']} — {r['fecha']}\n"
            texto += f"   Magistrado: {r['magistrado']}\n"
            texto += f"   Extracto: {r['extracto']}\n\n"

        return [types.TextContent(type="text", text=texto)]

    except ConnectionError as e:
        # Error de red — informar a Claude para que informe al usuario
        return [types.TextContent(
            type="text",
            text=f"No fue posible conectar con la Relatoría CSJ: {e}. Intenta en unos minutos."
        )]
    except Exception as e:
        # Error inesperado — loguear y devolver mensaje útil
        print(f"[ERROR] buscar_jurisprudencia: {e}")  # va al log de Railway
        return [types.TextContent(
            type="text",
            text=f"Error interno al buscar jurisprudencia. Detalle: {str(e)}"
        )]


# ── Implementación de obtener_sentencia ──────────────────────────────
async def _obtener_sentencia(args: dict) -> list[types.TextContent]:
    """Obtiene el texto completo de una sentencia."""

    radicado = args.get("radicado", "").strip()
    if not radicado:
        return [types.TextContent(type="text", text="Error: se requiere el número de radicado.")]

    try:
        sentencia = await _obtener_texto_sentencia(radicado)
        return [types.TextContent(type="text", text=sentencia)]
    except FileNotFoundError:
        return [types.TextContent(
            type="text",
            text=f"Sentencia {radicado} no encontrada en la Relatoría."
        )]


# ── Funciones de acceso a datos (simuladas) ──────────────────────────
async def _consultar_relatoria_csj(termino: str, sala: str, año: int) -> list[dict]:
    """
    EN PRODUCCIÓN: aquí harías una petición HTTP a relatoria.ramajudicial.gov.co
    o a la API que expongas con un scraper.
    Por ahora devuelve datos simulados.
    """
    # Simular latencia de red
    await asyncio.sleep(0.1)

    return [
        {
            "radicado": f"SC{1234 + hash(termino) % 100:04d}-{año}",
            "fecha": f"15 de marzo de {año}",
            "magistrado": "[MAGISTRADO PONENTE]",
            "extracto": f"Sobre {termino}: la Sala estableció que..."
        },
        {
            "radicado": f"SC{5678 + hash(termino) % 50:04d}-{año}",
            "fecha": f"8 de agosto de {año}",
            "magistrado": "[MAGISTRADO PONENTE]",
            "extracto": f"Reiteración doctrina sobre {termino}..."
        }
    ]

async def _obtener_texto_sentencia(radicado: str) -> str:
    await asyncio.sleep(0.1)
    return f"""CORTE SUPREMA DE JUSTICIA
SALA DE CASACIÓN CIVIL
Radicado: {radicado}

[TEXTO COMPLETO DE LA SENTENCIA]
[En producción: obtenido de la Relatoría CSJ]"""


# ── Autenticación básica ─────────────────────────────────────────────
# Para Railway: el token va en variable de entorno MCP_SECRET_TOKEN
MCP_TOKEN = os.environ.get("MCP_SECRET_TOKEN", "")

def validar_token(request_headers: dict) -> bool:
    """Valida que el request viene de un cliente autorizado."""
    if not MCP_TOKEN:
        return True  # sin token configurado = modo desarrollo
    auth = request_headers.get("Authorization", "")
    return auth == f"Bearer {MCP_TOKEN}"


# ── Entry point ──────────────────────────────────────────────────────
if __name__ == "__main__":
    # stdio_server conecta con Claude Code CLI via stdin/stdout
    # Para HTTP/SSE en Railway, ver mcp_server_http.py
    asyncio.run(
        stdio_server(servidor)
    )

3. Error handling en MCP

MCP distingue dos tipos de errores. Confundirlos causa comportamientos extraños:

TipoCuándo usarloCómo hacerlo
Error de protocolo Tool no existe, JSON malformado, método desconocido Lanzar ValueError o Exception — MCP lo convierte en error JSON-RPC
Error de negocio No se encontró la sentencia, la API de CSJ está caída, parámetro inválido Retornar TextContent con el mensaje de error — Claude lo lee y responde al usuario
Regla de oro: Si el error es "la tool funcionó pero no encontró lo que buscaba" — devuelve texto. Si el error es "algo rompió el protocolo" — lanza excepción. La diferencia es como "sentencia no encontrada" (negocio) vs "el servidor se cayó" (protocolo).

4. Testing de tools MCP sin Claude

La ventaja del SDK: puedes probar las tools directamente sin conectar Claude. Son funciones Python normales.

archivo: test_mcp_csj.py
"""
Tests para el MCP server de CSJ.
Correr: python -m pytest test_mcp_csj.py -v
"""

import asyncio
import pytest

# Importamos las funciones internas directamente
from mcp_csj_server import _buscar_jurisprudencia, _obtener_sentencia, ejecutar_tool


# ── Test 1: búsqueda básica funciona ────────────────────────────────
def test_busqueda_devuelve_resultados():
    resultados = asyncio.run(
        _buscar_jurisprudencia({"termino": "calificacion creditos"})
    )
    # Debe devolver lista con al menos un TextContent
    assert len(resultados) > 0
    assert resultados[0].type == "text"
    assert "calificacion creditos" in resultados[0].text.lower()


# ── Test 2: término vacío devuelve error útil ────────────────────────
def test_termino_vacio_retorna_error():
    resultados = asyncio.run(
        _buscar_jurisprudencia({"termino": ""})
    )
    assert "Error" in resultados[0].text


# ── Test 3: tool desconocida lanza excepción ─────────────────────────
def test_tool_desconocida_lanza_excepcion():
    with pytest.raises(ValueError, match="no existe"):
        asyncio.run(ejecutar_tool("tool_que_no_existe", {}))


# ── Test 4: radicado válido devuelve texto ───────────────────────────
def test_obtener_sentencia_valida():
    resultados = asyncio.run(
        _obtener_sentencia({"radicado": "SC1234-2023"})
    )
    assert "SC1234-2023" in resultados[0].text

5. Deployment en Railway (HTTP/SSE)

Ya conoces Railway. Agregar un MCP server es agregar un nuevo servicio al mismo proyecto.

archivo: mcp_server_http.py (versión para Railway)
"""
Versión HTTP/SSE del servidor MCP para Railway.
Usa la misma lógica de tools, distinto transport.
"""
from mcp.server.sse import SseServerTransport
from starlette.applications import Starlette
from starlette.routing import Route
import uvicorn, os

# Reusar el servidor ya definido en mcp_csj_server.py
from mcp_csj_server import servidor

sse = SseServerTransport("/messages/")

async def handle_sse(request):
    async with sse.connect_sse(
        request.scope, request.receive, request._send
    ) as streams:
        await servidor.run(
            streams[0], streams[1],
            servidor.create_initialization_options()
        )

# App ASGI para Railway
app = Starlette(routes=[
    Route("/sse", endpoint=handle_sse),
])

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 8080))
    uvicorn.run(app, host="0.0.0.0", port=port)
En Railway: Variable de entorno MCP_SECRET_TOKEN con un token secreto. En Claude.ai al configurar el conector: agrega el header Authorization: Bearer TU_TOKEN. Nadie más puede usar tu servidor.
