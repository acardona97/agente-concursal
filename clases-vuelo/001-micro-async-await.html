Async / Await — Código que no bloquea

Fundamentos de Calibración · Ya tienes principios de esto · Expandimos
Concepto

El código normal corre de arriba hacia abajo, línea a línea, esperando que cada operación termine antes de pasar a la siguiente. Si una operación tarda (llamar a una API, consultar una base de datos), el programa se congela esperando.

Código asíncrono dice: "Inicia esta operación lenta — yo sigo trabajando. Cuando termines, avísame." Las palabras async y await son la forma en que Python (y JavaScript) expresan esa idea.

async def declara una función que puede pausarse. await es el punto de pausa: "espera esto sin bloquear a otros."

Analogía Legal
Envías un memorial al juzgado y no te quedas parado en la ventanilla esperando el sello. Vuelves a tu oficina, sigues preparando otros escritos, atendiendo clientes. Cuando llega la notificación de recibo, la manejas. Eso es async/await: inicias una tarea que tomará tiempo y sigues con otras cosas.
Cómo Funciona

Síncrono vs Asíncrono

SÍNCRONO (bloqueante): ───────────────────── Programa ──► Llama API ──► ESPERA... ──► ESPERA... ──► Respuesta ──► Sigue Durante "ESPERA": el programa no hace NADA más. Si tienes 10 consultas, cada una espera a que termine la anterior. Tiempo total = suma de todos los tiempos. ASÍNCRONO (no bloqueante): ────────────────────────── Programa ──► Inicia consulta 1 ──► Inicia consulta 2 ──► Inicia consulta 3 │ │ │ ▼ ▼ ▼ [esperando...] [esperando...] [esperando...] │ ▼ (llega respuesta 2 primero) Procesa respuesta 2 │ ▼ (llega respuesta 1) Procesa respuesta 1 ... Tiempo total ≈ tiempo de la consulta MÁS LENTA (no la suma). EN AGENTES (por qué importa): ────────────────────────────── Agente Concursal recibe 5 preguntas simultáneas Síncrono: P1 ► P2 ► P3 ► P4 ► P5 (5 usuarios esperan en fila) Asíncrono: P1 │ (todos responden casi al mismo tiempo) P2 │ ← ChromaDB busca en paralelo P3 │ ← Claude API procesa en paralelo P4 │ P5 │
Código

Ejemplo mínimo en Python

python 
# async_ejemplo.py — Ejemplo mínimo de async/await
import asyncio

# "async def" convierte esta función en una "coroutine"
# Una coroutine es una función que PUEDE pausarse y reanudarse
async def consultar_juzgado(radicado: str) -> str:
    """Simula una consulta lenta a un sistema externo."""

    # "await" dice: "pausa aquí, deja que otros corran, y cuando
    # asyncio.sleep termine, reanúdame"
    # asyncio.sleep simula una operación lenta (API, DB, etc.)
    await asyncio.sleep(1)  # simula 1 segundo de espera

    return f"Radicado {radicado}: Auto de apertura recibido"


async def procesar_multiples_consultas():
    """Consulta 3 radicados en PARALELO usando asyncio.gather."""

    radicados = ["2025-0500", "2025-0501", "2025-0502"]

    # Sin async: 3 segundos (1+1+1)
    # Con asyncio.gather: ~1 segundo (corren en paralelo)
    resultados = await asyncio.gather(
        *[consultar_juzgado(r) for r in radicados]
    )

    for resultado in resultados:
        print(resultado)


# Para correr código async, necesitas el "event loop"
# asyncio.run() crea ese loop y ejecuta la función principal
asyncio.run(procesar_multiples_consultas())


# ─── En Flask (como tu agente concursal) ───
# Flask por defecto es síncrono.
# Puedes usar Flask con async views así:

from flask import Flask
app = Flask(__name__)

# Con "async def" Flask maneja la coroutine automáticamente
# (requiere pip install flask[async] o instalar "asgiref")
async def consulta_async():
    resultado = await consultar_juzgado("2025-0500")
    return resultado
