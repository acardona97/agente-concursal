MCP — cómo Claude se conecta con herramientas externas

Calibración · Tu agente YA tiene un MCP server. Esta clase lo explica.
Concepto

MCP (Model Context Protocol) es un protocolo abierto de Anthropic que define cómo Claude se comunica con herramientas externas. Es como una interfaz estándar: cualquier herramienta que "habla MCP" puede conectarse a Claude sin código personalizado.

La arquitectura es cliente-servidor: Claude actúa como cliente (llama herramientas), y tu servidor MCP expone esas herramientas con nombre, descripción y schema de parámetros. Claude decide cuándo llamar cada herramienta basado en su descripción.

MCP no reemplaza tu agente — lo hace accesible desde Claude.ai. Es el puente entre la interfaz de Claude y tu lógica de negocio en Flask.

Lo que YA tienes: mcp_server.py en tu repo es un servidor MCP completo integrado a Flask. Cuando Claude.ai lo conecta, puede llamar a consultar_agente_concursal y obtener respuestas del agente directamente desde el chat de Claude.
Diagrama — protocolo cliente-servidor MCP
CLIENTE (Claude.ai o tu app) ┌────────────────────────────────────┐ │ Claude (LLM) │ │ "Necesito consultar al agente" │ │ → llama: consultar_agente_concursal│ │ { "consulta": "Art. 49 Ley 1116"}│ └─────────────────┬──────────────────┘ │ HTTP JSON-RPC 2.0 │ POST /mcp │ { "method": "tools/call", │ "params": { ... } } ▼ SERVIDOR MCP (tu mcp_server.py en Railway) ┌────────────────────────────────────┐ │ Flask Blueprint "/mcp" │ │ ┌──────────────────────────────┐ │ │ │ tools/list → devuelve │ │ │ │ TOOLS = [{ │ │ │ │ "name": "consultar_...", │ │ │ │ "description": "...", │ │ │ │ "inputSchema": {...} │ │ │ │ }] │ │ │ └──────────────────────────────┘ │ │ ┌──────────────────────────────┐ │ │ │ tools/call → ejecuta │ │ │ │ consultar_agente() ────────┼──┤──→ ChromaDB │ │ generar_documento() ───────┼──┤──→ DOCX/XLSX │ └──────────────────────────────┘ │ └────────────────────────────────────┘ │ ▼ JSON response { "result": { "content": [{ "type": "text", "text": "..." }] } } │ ▼ CLIENTE recibe la respuesta → Claude la incorpora en su respuesta final
Tu mcp_server.py — anotado
TOOLS
Lista de herramientas que expone el servidor. Cada tool tiene nombre, descripción (Claude la lee para decidir cuándo usarla) y schema de entrada.
tools/list
Método que Claude llama al conectarse. Le dice qué herramientas están disponibles. Tu servidor devuelve la lista TOOLS.
tools/call
Método que Claude llama cuando quiere ejecutar una herramienta. Tu servidor recibe el nombre de la tool y los argumentos, ejecuta la lógica y retorna el resultado.
initialize
Handshake inicial. Claude envía su versión del protocolo, tu servidor confirma compatibilidad. Protocolo actual: "2024-11-05".
JSON-RPC 2.0
El formato de mensajes. Cada mensaje tiene "method", "params", "id" y "jsonrpc": "2.0". Tu servidor responde con "result" o "error".

Quarta — cómo conectar tu agente a Claude.ai hoy

Tu servidor MCP está corriendo en Railway. Para conectarlo a Claude.ai:

  1. Ve a Claude.ai → Settings → Integrations (o MCP)
  2. Agrega la URL: https://[tu-dominio-railway].up.railway.app/mcp
  3. Claude hará GET /mcp para descubrir las herramientas
  4. Cuando en Claude.ai pidas "consulta al agente concursal...", Claude llamará automáticamente tu tool
