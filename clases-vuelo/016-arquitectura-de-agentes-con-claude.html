Los tres tipos de agente: reactivo, planificador, ejecutor

No todos los agentes son iguales. La arquitectura correcta depende de cuánta autonomía necesita tu caso de uso:

Tipo¿Quién decide el próximo paso?Cuándo usarloEjemplo Quarta
Reactivo El modelo responde a cada input sin planificar hacia adelante Preguntas individuales, consultas puntuales Tu agente v1 actual
Planificador El modelo primero elabora un plan, luego lo ejecuta paso a paso Tareas multi-paso con dependencias "Prepara la oposición al proyecto de calificación del proceso X"
Ejecutor Un modelo coordinador delega a sub-agentes especializados Tareas complejas que necesitan expertise diferente en cada subtarea Orquestador → skills de concursal + jurisprudencia + redacción

Managed Agents API — la forma oficial de Anthropic

En lugar de manejar el loop del agente manualmente (enviar mensaje, revisar si necesita tools, ejecutar tools, enviar de nuevo…), la Managed Agents API abstrae ese loop. Tú defines las tools y el punto de entrada; la API maneja el ciclo.

"""
La forma MANUAL de hacer un loop de agente (lo que muchos hacen):
Requiere que tú manejes el ciclo while, los tool calls, etc.
"""

import anthropic
client = anthropic.Anthropic()

def loop_manual(pregunta: str, tools: list) -> str:
    mensajes = [{"role": "user", "content": pregunta}]

    while True:
        respuesta = client.messages.create(
            model="claude-opus-4-5",
            max_tokens=4096,
            tools=tools,
            messages=mensajes
        )

        # ¿El modelo terminó o quiere llamar una tool?
        if respuesta.stop_reason == "end_turn":
            return respuesta.content[0].text

        if respuesta.stop_reason == "tool_use":
            # Ejecutar cada tool que pidió el modelo
            tool_results = []
            for block in respuesta.content:
                if block.type == "tool_use":
                    resultado = ejecutar_tool(block.name, block.input)
                    tool_results.append({
                        "type": "tool_result",
                        "tool_use_id": block.id,
                        "content": resultado
                    })

            # Agregar resultados al historial y continuar el loop
            mensajes.append({"role": "assistant", "content": respuesta.content})
            mensajes.append({"role": "user", "content": tool_results})

        else:
            break

    return "No se pudo completar la tarea"
El problema del loop manual: Tú eres responsable de todo — manejo de errores, límites de iteración, logging, timeouts. La Managed Agents API encapsula esto.

Patrones de orquestación

Sequential
Paso 1 → Paso 2 → Paso 3. El output de cada paso es el input del siguiente. Más predecible.
Quarta: buscar jurisprudencia → analizar → redactar escrito
Parallel
Múltiples tools se ejecutan al mismo tiempo. Más rápido cuando las tareas son independientes.
Quarta: buscar CSJ + consultar SIIS al mismo tiempo
Map-Reduce
Un input → N sub-tareas paralelas → combinar resultados. Para procesar listas grandes.
Quarta: calificar cada crédito individualmente → combinar en proyecto
Fallback
Intentar con fuente A, si falla → fuente B, si falla → respuesta de default.
Quarta: buscar en ChromaDB → si no hay resultado → buscar en CSJ

Tool use avanzado: parallel calls, chaining, error recovery

Parallel tool calls

Claude puede llamar múltiples tools al mismo tiempo en una sola respuesta. Cuando el modelo sabe que dos tools son independientes, las lanza en paralelo:

# Cuando Claude responde con stop_reason="tool_use",
# puede incluir MÚLTIPLES tool_use blocks en content[]:

respuesta.content = [
    ToolUseBlock(
        id="call_1",
        name="buscar_contexto_normativo",
        input={"consulta": "calificacion creditos ley 1116"}
    ),
    ToolUseBlock(
        id="call_2",
        name="consultar_proceso_siis",
        input={"nit": "900123456"}
    )
    # Claude lanzó las dos al mismo tiempo
]

# Tu código debe ejecutarlas en paralelo con asyncio.gather()
import asyncio

async def ejecutar_tools_paralelas(tool_calls: list) -> list:
    tasks = [ejecutar_tool_async(tc.name, tc.input) for tc in tool_calls]
    resultados = await asyncio.gather(*tasks, return_exceptions=True)
    return resultados
