Clase 17 de 26
Progreso del curso

Preguntaste específicamente sobre skills — qué son, cómo los percibe Claude, cuándo los usa. Esta clase va directo a eso. Los skills son uno de los conceptos más mal entendidos del ecosistema de Claude Code, y son distintos de lo que se llama "skills" en Cowork. Vamos a separar todo.

Qué ES un skill en Claude Code

Un skill en Claude Code es un archivo Markdown (.md) que contiene instrucciones de tarea. No es código Python. No es una función. No es un plugin. Es un documento de texto que Claude lee y ejecuta como si fueran instrucciones de un experto.

Analogía legal perfecta

Un skill es como un protocolo de actuación de tu firma. El documento que dice exactamente cómo redactar un recurso de reposición: qué revisar primero, qué estructura usar, qué citar, cómo terminar. Un abogado nuevo lo lee y puede ejecutar la tarea con el estándar de la firma. Claude hace exactamente lo mismo con el skill.

Lo que un skill NO es:
No es código ejecutable. No es una MCP tool. No es un plugin de Chrome. No es una función que Claude "llama" — es un prompt especializado que Claude sigue cuando se activa.

La estructura de un skill

archivo: .claude/skills/calificacion-creditos.md
---
name: calificacion-creditos
description: Genera un proyecto de calificación y graduación de créditos
  bajo la Ley 1116. Usar cuando el abogado pide "calificar créditos",
  "proyecto de calificación" o "graduación de acreedores".
argument-hint: "nombre del proceso y lista de acreedores"
---

# Skill: Calificación y Graduación de Créditos
## Ley 1116 de 2006 — Arts. 49 a 52

Cuando se activa este skill, seguir estos pasos en orden:

### Paso 1: Recopilar información
Preguntar al abogado (si no está en el prompt):
- Nombre completo del deudor y NIT
- Lista de acreedores con: nombre, tipo de crédito, valor solicitado, documentos soporte
- Radicado del proceso
- Nombre del juez del concurso

### Paso 2: Clasificar según prelación
Aplicar el orden del Art. 2495 C.C. y normas especiales Ley 1116:
1. PRIMERA CLASE: gastos de administración del concurso (Art. 49 #1)
2. PRIMERA CLASE: créditos laborales (Art. 2495 #1 C.C.)
[continuar con las demás clases...]

### Paso 3: Generar el proyecto
Usar la estructura formal:
- Encabezado con despacho, radicado, proceso
- Tabla de clasificación con columnas: Acreedor | Valor Admitido | Clase | Prelación | Observaciones
- Fundamentos jurídicos por cada clase
- Petición al juez del concurso

### Reglas de confidencialidad
- Usar SIEMPRE placeholders para nombres de clientes actuales
- Si el abogado proporciona nombres específicos en la solicitud, usarlos solo para ese escrito

Cuándo Claude usa los skills — de entrada vs por contexto

Aquí está la distinción que más confunde:

Situación¿Cómo se activa el skill?
El usuario escribe /calificacion-creditos Activación explícita. Claude sabe exactamente qué skill ejecutar. Carga las instrucciones y las sigue.
El usuario escribe "quiero el proyecto de calificación del proceso X" Activación por contexto. Claude lee la descripción del skill, la compara con el prompt del usuario, y decide si este skill es relevante. La descripción del skill es el mecanismo de selección.
Claude Code CLI empieza sin mensaje del usuario Skills NO se cargan automáticamente. Claude solo los carga cuando son relevantes para la tarea.
La descripción del skill es crítica. Es lo que Claude lee para decidir si un skill aplica. Una descripción vaga → Claude no activa el skill cuando debería. Escribe la descripción como si le explicaras a un asistente nuevo cuándo usar este protocolo.

Cómo crear un skill personalizado

Dónde van los archivos

# Skills a nivel de proyecto (solo para tu agente concursal)
/home/user/agente-concursal/.claude/skills/
├── calificacion-creditos.md
├── redactar-recurso.md
├── proyecto-votos.md
└── analizar-acuerdo.md

# Skills a nivel global (disponibles en cualquier proyecto)
~/.claude/skills/
├── quarta-style-guide.md
└── formato-escritos-colombia.md

El ciclo de vida de un skill

1. Claude Code escanea .claude/skills/ al inicio de la sesión
2. Lee el frontmatter YAML de cada skill (name, description)
3. Construye un mapa interno: "si la tarea se parece a X, tengo el skill Y"
4. Cuando el usuario escribe algo, Claude evalúa si algún skill aplica
5. Si sí: carga el contenido completo del .md y lo sigue como instrucciones
6. El skill puede referenciar otros archivos del proyecto ($ARGUMENTS, $FILE_CONTEXT)

Skills en Cowork vs Skills en Claude Code CLI

Claude Cowork (web)
Interfaz visual para crear skills
Skills compartidos con el equipo
Se activan con /nombre-skill en el chat
No requieren repositorio Git
Más fáciles de crear para no-programadores
Limitados a la UI web de Cowork
Claude Code CLI
Archivos .md en .claude/skills/
Por proyecto o globales (~/.claude/)
Activación explícita /skill o por contexto
Viven en el repo Git — versionables
Pueden referenciar archivos del proyecto
Funcionan en el terminal y en proyectos de código
¿Cómo usar los skills de Cowork desde Claude Code CLI?
Los skills de Cowork están en la nube. Para usarlos desde CLI: exporta el contenido del skill de Cowork como archivo .md y guárdalo en .claude/skills/. Son el mismo formato. La diferencia es solo dónde viven y cómo se comparten.

Código completo: Skill /quarta:calificacion-creditos

.claude/skills/quarta-calificacion-creditos.md
---
name: quarta:calificacion-creditos
description: Genera el proyecto completo de calificación y graduación de créditos
  para un proceso concursal colombiano bajo la Ley 1116 de 2006.
  Activar cuando el abogado mencione: calificación, graduación, proyecto de créditos,
  clasificar acreedores, prelación de créditos, artículo 49 o 50 Ley 1116.
argument-hint: "[nombre proceso] + [lista de acreedores con valores y tipos]"
---

# Skill: Proyecto de Calificación y Graduación de Créditos
# Ley 1116 de 2006 — Arts. 49, 50, 51 y 52

## Antes de empezar

Si el abogado no proporcionó la información completa, preguntar EXACTAMENTE esto:

```
Para generar el proyecto de calificación necesito:

1. ¿Cuál es el nombre del proceso y el número de radicado?
2. ¿Cuál es el NIT del deudor?
3. Lista de acreedores en este formato:
   - Acreedor | Tipo de crédito | Valor solicitado | Clase propuesta (si la sabe)
4. ¿Hay créditos laborales, fiscales o con garantía real? Menciónelos.
5. ¿El abogado tiene posición sobre algún crédito controversia? ¿Cuál?
```

Si el abogado ya proporcionó todo, saltar directamente al Paso 2.

## Paso 2: Clasificar los créditos

Aplicar SIEMPRE este orden (Art. 2495 C.C. + Art. 49-52 Ley 1116):

**PRIMERA CLASE** (cobrar primero, Art. 2495 #1 C.C.):
- Gastos de administración del concurso (honorarios del promotor/liquidador)
- Créditos laborales: salarios, prestaciones, indemnizaciones (L. 1116 Art. 50 #1)
- Créditos del SENA, ICBF, Cajas de Compensación

**SEGUNDA CLASE** (Art. 2495 #2 C.C.):
- Créditos con prenda o garantía mobiliaria registrada
- Créditos hipotecarios (sobre el bien hipotecado)

**TERCERA CLASE** (Art. 2495 #3 C.C.):
- Créditos fiscales: impuestos nacionales (DIAN), departamentales, municipales
- Obligaciones parafiscales: EPS, ARL, fondos de pensión

**CUARTA CLASE** (Art. 2495 #4 C.C.):
- Créditos quirografarios simples (sin garantía ni prelación especial)
- La mayoría de los proveedores caen aquí

**QUINTA CLASE** (Art. 2495 #5 C.C.):
- Créditos subordinados (socios, vinculados económicos, accionistas)

## Paso 3: Generar el documento

Usar EXACTAMENTE esta estructura:

```
SUPERINTENDENCIA DE SOCIEDADES / JUZGADO [NÚMERO]
GRUPO DE PROCESOS ESPECIALES
PROCESO: [NOMBRE DEL PROCESO] (Reorganización / Liquidación judicial)
RADICADO: [NÚMERO]

[Ciudad], [fecha completa]

[NOMBRE DEL DESPACHO]:

[NOMBRE DEL PROMOVENTE], abogado de [PARTE], en el proceso de [tipo] de
[DEUDOR], respetuosamente presente:

PROYECTO DE CALIFICACIÓN Y GRADUACIÓN DE CRÉDITOS

I. CRÉDITOS DE PRIMERA CLASE

[Para cada crédito: tabla con Acreedor / Valor / Fundamento / Observación]

[continuar con cada clase...]

FUNDAMENTOS JURÍDICOS

[Citar artículos específicos por cada categoría]

PETICIÓN

Respetuosamente solicitar al despacho acoger el presente proyecto de
calificación y graduación de créditos como definitivo, o convocar a
audiencia para resolver las controversias que se susciten.
```

## Reglas de confidencialidad (OBLIGATORIAS)

- NUNCA usar nombres reales de clientes de documentos indexados en ChromaDB
- Usar SIEMPRE: [DEUDOR], [ACREEDOR], [PROVEEDOR], [TRABAJADOR], [ENTIDAD]
- Si el abogado proporciona nombres en la solicitud, usarlos SOLO para ese escrito
- Los montos específicos de documentos indexados deben reemplazarse con [VALOR]

Quarta Legal Hub · Los 5 Skills Más Útiles

/quarta:calificacion-creditos

Genera el proyecto completo de calificación y graduación. El skill más usado en derecho concursal. Construir primero.

/quarta:redactar-objecion

Redacta memorial de objeción a crédito específico. Pide: acreedor objetado, valor reclamado, valor que reconoces, fundamento jurídico de la objeción.

/quarta:proyecto-votos

Genera el proyecto de votos para deliberación de junta. Calcula quórums y mayorías según tipo de acuerdo (Art. 29-30 Ley 1116).

/quarta:recurso-reposicion

Estructura el recurso contra autos del juez del concurso. Pide: auto recurrido, fecha, fundamentos de la impugnación.

/quarta:analisis-acuerdo

Analiza un acuerdo de reorganización en borrador: identifica cláusulas problemáticas, verifica requisitos legales, sugiere modificaciones.
