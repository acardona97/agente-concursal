Prompting para documentos legales

Redacción de memoriales, citas verificadas y el patrón role+jurisdiction+audience
Concepto

Prompting para documentos legales no es solo "pedir un escrito". Es especificar tres dimensiones que determinan el output: rol (qué función cumple el autor), jurisdicción (qué normas aplican), y audiencia (para quién se escribe). Cambiar cualquiera de las tres produce un documento diferente.

Para documentos legales, el formato del output es tan importante como el contenido. Un memorial con markdown (asteriscos, bullets) enviado al juzgado se ve amateur. Un JSON de calificación de créditos es más útil para el agente que texto plano. La elección correcta depende del destino del documento.

Patrón role + jurisdiction + audience
ROL: "Como abogado concursalista colombiano actuando como agente" JURISDICCIÓN: "en proceso de reorganización bajo Ley 1116 de 2006 ante Supersociedades" AUDIENCIA: "para presentar al Despacho de Insolvencia [radicado]" TAREA: "redacta un memorial de objeción al crédito de [ACREEDOR]" HECHOS: "por las siguientes razones: [hechos del caso]" RESTRICCIÓN: "cita solo artículos verificados de la Ley 1116. Usa [VERIFICAR] si hay duda."

Cada elemento del patrón modifica el output de forma específica:

  • Rol: define el vocabulario y el nivel de formalidad (forense colombiano)
  • Jurisdicción: activa el marco normativo correcto (Ley 1116, no ley española)
  • Audiencia: define el destinatario y por tanto el tono y estructura esperada
Cómo pedir citas verificadas — el patrón anti-alucinación

El mayor riesgo en documentos legales: Claude cita un artículo que no existe, o cita uno que sí existe pero con contenido incorrecto. El patrón del repo claude-for-legal: 

# Patrón para solicitar citas verificadas en documentos legales
# Incluir en el prompt de cada solicitud de escrito

PATRON_CITAS_VERIFICADAS = """
<instrucciones_citas>
REGLAS PARA CITAS NORMATIVAS (OBLIGATORIAS):

1. Solo cita artículos que estén en el contexto normativo que recibes.
   Si el artículo no aparece en el contexto, escribe literalmente:
   [VERIFICAR: Art. X Ley Y]

2. Cuando cites jurisprudencia, incluye:
   - Sala (ej: Sala de Casación Civil)
   - Fecha aproximada (ej: "sentencia de 2019")
   - Radicado si lo conoces
   Si no tienes certeza de algún dato: [VERIFICAR: radicado/fecha sentencia]

3. Para normas de la Ley 1116, el formato correcto es:
   "...según el artículo 49 de la Ley 1116 de 2006..."
   NO: "Art. 49 L1116" (abreviación informal)
   NO: "el artículo 49 del estatuto concursal" (sin citar la ley)

4. Si el abogado pide fundamentar algo que no tiene base normativa clara,
   di explícitamente: "Este punto no tiene sustento directo en la Ley 1116.
   Se sugiere fundamentar en [alternativa] o bajo criterio discrecional del juez."
</instrucciones_citas>
"""
Formato de output — cuándo usar cada uno

Texto Plano

  • Memoriales para imprimir
  • Escritos que van al juzgado
  • Documentos para Word/.docx
  • Cuando el abogado copia y pega

Markdown

  • Análisis internos de Quarta
  • Respuestas en el chat del agente
  • Documentos que se renderizan en web
  • Resúmenes de jurisprudencia

JSON

  • Tablas de calificación de créditos
  • Proyectos de votos estructurados
  • Datos para exportar a Excel
  • Integración con otras herramientas
Regla práctica: si el documento va a un juzgado o se imprime → texto plano. Si se procesa por código → JSON. Si se lee en pantalla → markdown. Especifica esto en el prompt: "Devuelve el escrito en texto plano sin formato markdown."

<audiencia>

</audiencia>

<hechos_del_caso>
Proceso: [NOMBRE DEL PROCESO]

Valor del crédito: [VALOR EN PESOS]
Clase que debería tener según el objetor: [CLASE CORRECTA]
Razón de la objeción: [RAZÓN JURÍDICA - ej: "el crédito tiene naturaleza laboral conforme al Art. 2495 C.C."]
</hechos_del_caso>

<tarea>
Redacta el memorial de objeción al proyecto de calificación y graduación de créditos.
Estructura requerida:
1. Encabezado completo (Despacho, Radicado, Identificación del objetor, Proceso)
2. Hechos (mínimo 4, numerados, que fundamenten la objeción)
3. Fundamentos jurídicos (con citas exactas de la Ley 1116 y Código Civil)
4. Petición principal: que se reclasifique el crédito

</tarea>

</instrucciones_formato>

Quiz — 3 preguntas
Pregunta 1 / 3
Un colega de Quarta quiere generar el mismo memorial de objeción pero en formato para publicar en la intranet (con títulos, bullets, negritas). ¿Qué cambio mínimo hace al template para obtener ese formato?
Solo cambiar la sección <instrucciones_formato>. Reemplazar "Texto plano, sin markdown" por "Formato markdown: usa ## para secciones, **negritas** para términos jurídicos clave, listas con - para los hechos." El resto del template (rol, jurisdicción, audiencia, estructura) permanece igual. Esta es precisamente la ventaja del patrón XML: los cambios están aislados en su sección, no requieren reescribir todo el prompt.
Pregunta 2 / 3
¿Por qué el patrón de citas verificadas usa el placeholder [VERIFICAR: Art. X Ley Y] en lugar de simplemente decirle a Claude "no inventes artículos"?
Porque el placeholder hace el error visible y accionable. "No inventes artículos" es una negación — Claude puede cumplirla omitiendo la cita (lo que también es un problema) o ignorándola. [VERIFICAR: Art. X Ley Y] es una instrucción positiva: "cuando no estés seguro, pon esto exactamente." El resultado es un documento donde el abogado puede hacer Ctrl+F de "[VERIFICAR" y encontrar todos los puntos que necesitan revisión antes de firmar. Es más útil que un documento que parece perfecto pero tiene artículos inventados.
Pregunta 3 / 3
El template de objeción tiene la sección <audiencia> que especifica "Juez del proceso de reorganización de Supersociedades". Si el mismo escrito se redactara para una audiencia diferente (por ejemplo, para el acreedor objetado, como comunicación directa), ¿cambiaría el output? ¿Por qué?
Sí, cambiaría significativamente. Para el Despacho judicial: lenguaje forense formal, estructura de memorial procesal (Hechos/Fundamentos/Petición), tono neutro y respetuoso al juzgado. Para el acreedor objetado: podría ser una carta menos formal, con argumentos más negociadores (si se busca acuerdo), sin estructura de memorial procesal, y con un tono diferente. La <audiencia> es el parámetro que más impacta el tono y estructura del documento — mismo contenido fáctico, estilo completamente diferente.
