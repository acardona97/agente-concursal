Progreso del curso

El repositorio claude-for-legal de Anthropic tiene conectores para el mundo anglosajón: Ironclad (contratos), CourtListener (sentencias de EEUU), iManage (DMS), Everlaw (litigios). Ninguno sirve directamente para Colombia. Esta clase mapea sus equivalentes colombianos y define qué construir primero para Quarta.

La lectura correcta

No se trata de copiar esos conectores — se trata de entender el patrón: cada conector es un MCP server que sabe cómo hablar con una fuente de datos específica y expone tools granulares. Tu trabajo es construir los mismos patrones para las fuentes colombianas.

Cómo construir un conector personalizado

Un conector para fuentes colombianas tiene siempre la misma estructura:

# Capa 3: Acceso a datos (cómo llega a la fuente)
async def _fetch_siis(nit: str) -> dict:

Conector prioritario: CSJ Relatoría

"""
mcp_csj_relatoria.py
Conector MCP para la Relatoría de la Corte Suprema de Justicia.
URL base: https://relatoria.ramajudicial.gov.co

Estado actual (2025): el sitio tiene búsqueda por formulario HTML.
No hay API REST pública documentada.
Estrategia: scraper con httpx + BeautifulSoup + caché SQLite.
"""

import httpx
import asyncio
from bs4 import BeautifulSoup
import sqlite3, json, time
from pathlib import Path

RELATORIA_URL = "https://relatoria.ramajudicial.gov.co/SIICSA/busqueda"
CACHE_DB = Path("./cache/csj_cache.db")

# Caché SQLite simple — evita martillar el servidor de la Rama
def _init_cache():
    CACHE_DB.parent.mkdir(exist_ok=True)
    conn = sqlite3.connect(CACHE_DB)
    conn.execute("""CREATE TABLE IF NOT EXISTS cache
                    (key TEXT PRIMARY KEY, value TEXT, ts INTEGER)""")
    conn.commit()
    return conn

async def buscar_relatoria(termino: str, sala: str = "Civil", año: int = 2024) -> str:
    """
    Busca en la Relatoría CSJ.
    Retorna texto formateado con los resultados.
    """
    conn = _init_cache()
    cache_key = f"csj:{termino}:{sala}:{año}"

    # Revisar caché (TTL: 24 horas — la jurisprudencia no cambia)
    row = conn.execute(
        "SELECT value FROM cache WHERE key=? AND ts>?",
        (cache_key, int(time.time()) - 86400)
    ).fetchone()

    if row:
        return json.loads(row[0])

    # Si no hay caché: hacer la petición
    async with httpx.AsyncClient(timeout=15.0) as client:
        try:
            response = await client.post(
                RELATORIA_URL,
                data={
                    "texto": termino,
                    "sala": sala,
                    "anio": str(año)
                },
                headers={"User-Agent": "Quarta-Legal-Hub/1.0"}
            )
            resultado = _parsear_resultados(response.text, termino)
        except httpx.TimeoutException:
            return "No fue posible conectar con la Relatoría CSJ. Verifique su conexión."

    # Guardar en caché
    conn.execute(
        "INSERT OR REPLACE INTO cache VALUES (?,?,?)",
        (cache_key, json.dumps(resultado), int(time.time()))
    )
    conn.commit()
    return resultado

def _parsear_resultados(html: str, termino: str) -> str:
    """Extrae resultados del HTML de la Relatoría."""
    soup = BeautifulSoup(html, "html.parser")
    resultados = []
    # El parsing específico depende del DOM actual de la Relatoría
    # Ajustar los selectores según la estructura del sitio
    for item in soup.select(".resultado-jurisprudencia"):
        radicado = item.select_one(".radicado")
        fecha    = item.select_one(".fecha")
        extracto = item.select_one(".extracto")
        if radicado:
            resultados.append(f"• {radicado.text} ({fecha.text if fecha else 'fecha?'})\n  {extracto.text[:200] if extracto else ''}")

    if not resultados:
        return f"Sin resultados para '{termino}' en la Relatoría CSJ."
    return "\n\n".join(resultados[:10])  # máximo 10 resultados

¿Por qué empezar con CSJ + SIIS?

La lógica de priorización viene del trabajo diario de Quarta:

  • CSJ Relatoría: Es el primer lugar que buscas antes de presentar cualquier escrito en concursal. Tener jurisprudencia disponible en segundos dentro de Claude cambia el flujo de trabajo completamente.
  • SIIS Supersociedades: Para verificar el estado actual de los procesos de tus clientes. La información que ya tienes en ChromaDB puede estar desactualizada — SIIS tiene el estado en tiempo real.
  • BanRep: La API es la más fácil de todas (REST pública, bien documentada) y tiene alto impacto para calcular indexaciones e intereses en los proyectos de calificación.
Recomendación de arquitectura: No mezcles los conectores con tu Flask app actual. Crea un repositorio separado quarta-mcp-connectors que corra como un servicio independiente en Railway. Tu Flask app sigue siendo la interfaz de usuario. Los conectores son la capa de datos externa.
