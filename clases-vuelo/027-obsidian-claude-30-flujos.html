Obsidian + Claude — 30 Flujos, Plugins y Setups

El sistema completo para convertir Obsidian en un segundo cerebro potenciado por IA.

Introduccion

Obsidian tiene mas de 2700 plugins comunitarios. Mas de 100 son de IA. El CEO de Obsidian publico Skills oficiales para Claude. El ecosistema Obsidian+Claude esta explotando en 2026.

La mayoria de personas usa Obsidian como un bloc de notas avanzado y Claude como un chatbot. Estan perdiendo la capa de integracion que los convierte en algo cualitativamente mas poderoso: un sistema donde tus notas se convierten en el contexto persistente de Claude, y donde Claude organiza, conecta y amplifica el conocimiento que acumulas con el tiempo.

El problema central

Claude sin vault es amnesia. Vault sin Claude es una biblioteca sin indice. La combinacion resuelve ambos problemas: Claude recuerda todo lo que esta en tu vault, y tu vault se mantiene organizado y conectado gracias a Claude.

Parte 1: Los 10 Plugins Esenciales

De los mas de 2700 plugins disponibles, estos diez forman la base de cualquier setup serio de Obsidian con IA.

01Smart Connections

El plugin de IA mas popular de Obsidian. Usa RAG (Retrieval-Augmented Generation) para que puedas chatear con todo tu vault. Le preguntas "Que se sobre retencion de clientes?" y el plugin busca en todas tus notas, encuentra las relevantes y responde usando tu propio conocimiento acumulado.

Gratis para modelos locales. El costo en nube varia segun el proveedor que elijas (OpenAI, Anthropic, etc.).

Por que importa: Convierte un vault pasivo de notas en una base de conocimiento activa con la que puedes conversar directamente dentro de Obsidian.

02Copilot

Q&A basado en RAG con una interfaz de chat limpia integrada dentro de Obsidian. Soporta Claude, GPT, Gemini y modelos locales. Para quienes quieren la conversacion con IA dentro de Obsidian sin salir a una ventana del navegador.

Diferencia con Smart Connections: Copilot tiene una interfaz de chat mas convencional. Smart Connections tiene mas funciones de conexion automatica de notas. Muchos usuarios instalan los dos.

03Templater

Plantillas automaticas de notas que se ejecutan cuando creas tipos especificos de notas. Configura una plantilla de reunion que automaticamente agrega fecha, campo de asistentes, seccion de items de accion y tags de frontmatter. Cada nota empieza estructurada y lista para IA.

Combinacion critica: Templater + Claude es especialmente poderoso porque el formato consistente mejora dramaticamente la recuperacion de informacion. Claude puede leer mil notas de reunion con la misma estructura y extraer patrones con precision.

04Dataview

Convierte tu vault en una base de datos consultable. Puedes hacer queries como "Mostrame todas las notas etiquetadas #proyecto-alpha creadas en los ultimos 30 dias" y obtienes una tabla en vivo dentro de cualquier nota.

Cuando Claude lo usa: Puede responder preguntas sobre tu vault usando datos estructurados de Dataview, no solo busqueda de texto completo. La diferencia es la misma que entre buscar en Google y hacer una consulta SQL.

05Tasks

Gestion completa de tareas dentro de tus notas. Crea tareas en cualquier nota con fechas limite, prioridades y recurrencia. Consulta todas las tareas de tu vault en una sola vista, sin importar en que nota esten.

Con Claude: Claude puede leer cada tarea de tu vault y ayudarte a priorizar, reprogramar y hacer seguimiento. Si le describes tu semana, Claude sabe exactamente que esta pendiente.

06Obsidian Git

Control de versiones para tu vault. Auto-commits cambios en intervalos establecidos (por ejemplo, cada 30 minutos). Tus notas tienen historial completo: puedes ver que cambio, cuando cambio y revertir si es necesario.

Caso de uso critico: Si tu vault es central a tu trabajo profesional (como lo es para un abogado), perder notas no es una opcion. Git te da resguardo automatico y la posibilidad de recuperar cualquier version.

07Calendar

Vista de calendario visual de tus notas diarias. Haz clic en cualquier fecha para ver o crear la nota de ese dia. Simple, pero transforma la consistencia del habito de notas diarias.

Para Claude: Cuando mantienes notas diarias consistentemente, Claude tiene un registro cronologico de tu trabajo, ideas y decisiones en el tiempo. Puede responder preguntas como "cuando tome esta decision y cuales fueron mis razones".

08Kanban

Convierte cualquier nota en un tablero Kanban visual. Rastrea etapas de proyectos, pipelines de contenido o flujos de trabajo. Las columnas son flexibles: puedes tener "Idea / En curso / En revision / Publicado" para contenido o "Prospecto / Propuesta / Negociacion / Cerrado" para ventas.

Con Claude: Puedes pedirle a Claude que revise el tablero, identifique cuellos de botella y sugiera que mover.

09Periodic Notes

Automatiza la creacion de notas diarias, semanales, mensuales y trimestrales con plantillas. No tienes que recordar crear la nota del dia — la plantilla aparece sola con la estructura correcta.

El efecto compuesto: Con Periodic Notes, tu vault construye un registro estructurado en el tiempo que Claude puede analizar para patrones, tendencias y progreso a lo largo de cualquier periodo. "Como ha evolucionado mi foco en los ultimos tres meses" se convierte en una pregunta que Claude puede responder.

10Obsidian CLI

Lanzado en 2026. Interfaz de linea de comandos para Obsidian. Crea notas, busca y gestiona tu vault directamente desde la terminal, sin necesidad de que la interfaz grafica de Obsidian este abierta.

Por que cambia todo: Esto es lo que hace la integracion Claude Code + Obsidian completamente fluida. Claude Code puede llamar comandos CLI para interactuar con el vault programaticamente: crear notas de resumen, leer contenido de notas especificas, buscar en el vault. La integracion se vuelve automatizable.

# Ejemplo: Claude Code crea una nota en el vault
obsidian new "Reuniones/2026-06-02-cliente-abc.md" \
  --content "## Reunion Cliente ABC\nFecha: 2026-06-02\n..."

# Buscar notas relevantes
obsidian search "proceso concursal" --limit 5

Parte 2: Los 10 Flujos de Trabajo

Los plugins son la infraestructura. Los flujos de trabajo son los habitos y procesos que extraen el valor. Estos diez flujos cubren los casos de uso mas impactantes.

11The Morning Synthesis

Cada manana, Claude lee tus notas diarias de los ultimos tres dias mas tus notas de proyectos activos. Crea automaticamente una nota "Start of Day" en tu carpeta diaria con cuatro secciones:

  • Donde lo dejaste ayer
  • Que vence hoy
  • Que esta vencido
  • Una prioridad de foco sugerida para la sesion

Lo lees con el cafe y sabes exactamente por donde empezar. Sin tiempo perdido en orientarte.

12The Meeting Processor

Despues de cada reunion, pegas tus notas en bruto en una nota nueva (no importa el formato, pueden ser fragmentos). Claude las lee y produce:

  • Items de accion con responsables y fechas limite
  • Decisiones clave tomadas
  • Enlaces a notas de proyectos relevantes en tu vault
  • Tags apropiados para encontrar la nota despues

Un volcado de cinco minutos se convierte en un registro estructurado, enlazado y buscable.

13The Research Ingestion Pipeline

Guardas la URL de un articulo o pegas una transcripcion de PDF en tu carpeta Inbox. Claude la lee y crea:

  • Una nota de resumen con los insights clave
  • Enlaces a notas existentes sobre el mismo tema
  • Metadatos de fuente (autor, fecha, URL)
  • Marcadores de cualquier contradiccion con tu conocimiento existente

Un comando convierte input crudo en conocimiento conectado.

14The Weekly Review Automation

Cada viernes, Claude escanea todas las notas creadas o modificadas esa semana y crea una nota de revision semanal con: logros de la semana, decisiones tomadas, patrones notados en tu trabajo y prioridades para la proxima semana.

Tu revision semanal toma dos minutos en leer en lugar de una hora en crear.

15The Idea Cross-Pollinator

Tienes una idea en una nota. Le preguntas a Claude: "Encuentra todas las notas en mi vault que podrian conectarse con esta idea de forma no obvia."

Claude busca toda tu base de conocimiento y encuentra conexiones que nunca habrias encontrado manualmente. Los enlaces inesperados entre temas no relacionados son donde viven los mejores insights. Un abogado puede descubrir que un caso de 2019 tiene una estructura contractual identica al problema que enfrenta hoy.

16The Project Kickoff Generator

Cuando empiezas un nuevo proyecto, le dices a Claude los objetivos, restricciones y plazos. Claude crea una carpeta de proyecto completa con:

  • Nota de vision general del proyecto
  • Nota de tareas con hitos
  • Enlace a todas las notas del vault relevantes para este proyecto
  • Lista de brechas de conocimiento que necesitas llenar
  • Plantilla para actualizaciones semanales del proyecto

17The Vault Health Check

Mensualmente, Claude audita tu vault y genera un reporte de mantenimiento con:

  • Notas huerfanas sin enlaces entrantes
  • Notas con informacion desactualizada
  • Proyectos que se han paralizado sin actualizaciones en dos semanas
  • Tags que se usan de forma inconsistente
  • Campos de frontmatter que faltan

Tu vault se mantiene organizado sin esfuerzo manual.

18The Book Notes System

Cuando terminas de leer un libro, creas una nota con tus highlights y pensamientos. Claude la lee junto con todas tus notas existentes y produce:

  • Resumen de las ideas clave
  • Conexiones con tu conocimiento existente
  • Takeaways accionables especificos para tus proyectos actuales
  • Lista de otros libros o temas a explorar basada en las intersecciones

Cada libro que lees no es un silo — entra a la red de conocimiento.

19The Argument Builder

Trabajando en una presentacion, articulo o propuesta? Dale a Claude tu tesis. Busca en tu vault toda la evidencia de apoyo: datos, investigacion pasada, citas de notas de libros, resultados relevantes de proyectos.

Los organiza en un argumento estructurado con la evidencia mas fuerte primero. Para un abogado, esto significa que la investigacion juridica de anos anteriores se reutiliza automaticamente.

20The Decision Journal

Antes de tomar una decision importante, creas una nota con las opciones y tu pensamiento actual. Despues de que la decision se desarrolla, regresas y registras el resultado.

Con el tiempo, Claude puede analizar tu diario de decisiones e identificar patrones: que tipos de decisiones tiendes a acertar, donde aparecen tus sesgos cognitivos, que factores deberian pesar mas en decisiones futuras. Es un sistema de mejora continua basado en tus propios datos.

Parte 3: Los 10 Setups Avanzados

Los flujos de trabajo son los procesos. Los setups avanzados son las configuraciones de infraestructura que los hacen posibles o los potencian significativamente.

21Claude Code + Vault como Memoria Persistente

En tu archivo CLAUDE.md, defines tu vault de Obsidian como la memoria a largo plazo de Claude. La configuracion basica:

# Memory
Long-term memory lives in ~/vault/obsidian/.
Before starting any task, read relevant notes.
Write findings to new notes in ~/vault/obsidian/claude-outputs/.
Tag all generated notes with #ai-generated.

Claude lee notas relevantes antes de comenzar cualquier tarea, escribe hallazgos en nuevas notas y construye conocimiento acumulado entre sesiones. Tu vault se convierte en el cerebro de Claude entre sesiones.

22mcpvault MCP Server

Servidor MCP de cero dependencias que lee tu vault sin que Obsidian este ejecutandose. Tiene busqueda BM25 con clasificacion por relevancia, maneja frontmatter de forma segura y expone 14 metodos MCP.

Funciona con Claude Desktop, Claude Code, Cursor y Windsurf. Es la opcion MCP mas limpia para la mayoria de usuarios.

# Instalacion
npm install -g mcpvault

# En claude_desktop_config.json:
{
  "mcpServers": {
    "vault": {
      "command": "mcpvault",
      "args": ["--vault", "/ruta/a/tu/vault"]
    }
  }
}

Una vez conectado, Claude puede hacer busquedas semanticas en tu vault, leer notas especificas y escribir nuevas notas directamente desde Claude Desktop o Claude Code.

23Official Obsidian Skills de Steph Ango

El CEO de Obsidian construyo estas Skills directamente. Cinco skills que cubren notas markdown, archivos canvas y la Obsidian CLI. Mas de 12900 estrellas en GitHub.

Siguen la especificacion abierta de Agent Skills para que cualquier agente compatible pueda usarlas. Esta es la forma oficialmente respaldada de dejar que agentes IA trabajen con Obsidian.

Las Skills incluyen: crear notas, editar notas existentes, leer el contenido de notas, buscar en el vault y manipular archivos canvas (los lienzos visuales de Obsidian).

24obsidian-second-brain Skill

31 comandos para operar un vault de Obsidian como un segundo cerebro AI-first. Incluye:

  • Gestion completa del vault
  • Herramientas de pensamiento que debaten contigo usando tus propias notas
  • Agentes programados que corren en horarios especificos
  • Toolkit de investigacion que extrae posts en vivo de X via Grok
  • Investigacion web via Perplexity integrada directamente en notas estructuradas
  • Transcripciones de YouTube directamente en notas del vault

Es un setup mas ambicioso que las Skills oficiales, disenado especificamente para el uso AI-first del vault.

25Multi-Vault Strategy

Vaults separadas para contextos separados. La estructura tipica:

  • Vault personal: diario, reflexiones, vida personal
  • Vault de trabajo: proyectos profesionales, clientes, decisiones
  • Vault de aprendizaje: cursos, libros, investigacion

Claude se conecta a la vault relevante para la tarea. Sin mezcla entre entradas del diario personal y notas de proyectos de trabajo. El contexto permanece limpio.

26Obsidian + Claude Code Routines

Configura una Rutina de Claude Code que se ejecute nocturnamente contra tu vault. El ejemplo mas practico:

Cada noche a las 2am, Claude escanea notas nuevas en la carpeta Inbox, las archiva en la ubicacion correcta segun su contenido, agrega tags y enlaces relevantes, y crea una nota "procesado-de-noche.md" con un resumen de lo archivado.

Te despiertas con una vault organizada cada manana.

27Graph View Analysis

La Vista de Grafo de Obsidian muestra conexiones visuales entre todas tus notas. Con cientos de notas se vuelve ruidosa y dificil de interpretar manualmente.

Pide a Claude que analice el grafo e identifique:

  • Hubs: notas que conectan muchos otros nodos (tus ideas o temas mas centrales)
  • Clusters: grupos de notas relacionadas que forman areas de conocimiento
  • Brechas: clusters que no estan conectados entre si pero deberian estarlo

El analisis de grafo revela la estructura real de tu conocimiento, no la estructura que crees que tienes.

28Zettelkasten + IA

El metodo Zettelkasten — notas atomicas con IDs unicos y enlaces explicitos entre ellas — fue disenado por Niklas Luhmann para su cerebro humano. Funciona aun mejor con cerebros de IA.

Claude puede seguir cadenas de enlaces Zettelkasten para razonar sobre temas complejos usando tu conocimiento acumulado. Cada nota atomica es un paso de razonamiento. Claude los encadena.

La combinacion Zettelkasten + Claude es probablemente el sistema de gestion del conocimiento mas poderoso disponible hoy para trabajo intelectual serio.

29Vault-Powered Claude Projects

Exportas secciones clave de tu vault como archivos de conocimiento para Proyectos en Claude.ai. El mapeo:

  • Tu area "Marketing" se convierte en la base de conocimiento del proyecto "Produccion de Contenido"
  • Tu area "Derecho Concursal" se convierte en la base de conocimiento del proyecto legal
  • Tu area "Inversiones" alimenta el proyecto de analisis financiero

Cada Proyecto Claude extrae del segmento relevante de tu vault, sin contaminar el contexto con informacion de otras areas.

30The Feedback Loop System

El setup mas poderoso a largo plazo. Cuando Claude produce algo usando tu vault — un resumen, un analisis, una recomendacion — guardas el output de vuelta en tu vault como una nueva nota etiquetada con #ai-generated.

Con el tiempo, tu vault contiene tanto tu pensamiento original como la sintesis de Claude. Cada uno construye sobre el otro. El conocimiento se compone exponencialmente: tus nuevas notas son mas ricas porque Claude tiene mas contexto, y los outputs de Claude son mas precisos porque el vault es mas completo.

El efecto a 12 meses: Un vault con feedback loop activo durante un ano es cualitativamente diferente a un vault que solo tiene tus notas manuales. Es un segundo cerebro que aprende.

Como Empezar Hoy

El plan de implementacion en dos semanas:

Hora 1

Descarga Obsidian. Crea tu vault con estructura de carpetas PARA (Projects/Areas/Resources/Archive). Instala Templater y crea plantillas para notas diarias y de reuniones. No necesitas tener las plantillas perfectas en esta hora — solo usables.

Hora 2

Instala Smart Connections. Configura con Claude o GPT. Ten tu primera conversacion con tu vault, aunque solo tenga dos o tres notas. El objetivo es sentir como funciona el RAG sobre contenido propio.

Hora 3

Configura mcpvault (es el mas simple). Conectalo a Claude Desktop o Claude Code. Ejecuta tu primera consulta cross-vault desde Claude. Pregunta algo sobre las notas que ya tienes.

Dia 2

Crea 10 notas sobre tus proyectos y areas de enfoque actuales. No tienen que ser perfectas. El vault necesita masa critica para que el RAG sea util.

Dia 3

Construye tu primer flujo automatizado: la Morning Synthesis. Configura Claude Code para que genere tu nota de inicio de dia usando las notas de los ultimos tres dias.

Semana 1

Instala Periodic Notes y Dataview. Construye el habito de notas diarias y revisiones semanales. Agrega Obsidian Git para que todo se versione automaticamente.

Semana 2

Ya estas ejecutando un segundo cerebro potenciado por IA. Agrega los flujos de trabajo segun tu necesidad: Meeting Processor si tienes muchas reuniones, Argument Builder si produces documentos, Book Notes System si lees frecuentemente.

Incorrecto. La ventaja de Dataview es convertir el vault en una base de datos consultable. Claude puede responder preguntas usando datos estructurados, no solo busqueda de texto completo.

Incorrecto. La ventaja de mcpvault es precisamente que no requiere que Obsidian este ejecutandose y tiene cero dependencias adicionales. Funciona con multiples clientes IA.
